# Calculadora_de_Consumo_Eletrico
A Calculadora de Consumo de Energia é um projeto proposto pelo curso de Desenvolvimento de Sistemas que estou inscrita.

O projeto foi desenvolvido em Python.

O objetivo é ajudar os usuários a estimar quanto um aparelho gasta de energia elétrica por mês da seguinte forma: (potência do aparelho * média de uso diária * 30 dias) / 1000

Basta fornecer o aparelho a que se refere, sua potência e a média de uso diária.

Além disso, a calculadora conta com um cálculo de custo estimado considerando um valor fixo de 0,75 kWh.
